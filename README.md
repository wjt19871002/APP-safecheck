   ## 产品简介

   **幸福传承（SafeCheck）** 是一款专注于**日常报平安**与**个人重要备忘加密保存**的应用工具（支持 **Android APP** 与 **微信小程序**）：

   - **日常安全签到**：每天轻点一下即可报平安，支持连续签到统计、日历记录与每日提醒时间设置。
   - **端上加密备忘**：重要账号提示、家庭联系说明、生活备忘等全部在手机本地使用 **AES-256-GCM** 加密保存，支持独立「便签密码锁」。
   - **授权关怀机制（VIP 服务）**：在用户本人明确授权并设定规则后，如连续多日未按时签到，平台将启动人工核实并与紧急联系人沟通确认，守护独居人群、高危运动人群、病友等与家庭成员的日常安全。
   - **个人定制服务**：VIP用户可以根据需求，定制个性化服务（例如：电子产品格式化、资产处理等）。

   ## 隐私与安全设计原则

   1. **端上加密，平时不可见**：你保存的便签内容在离开手机前已完成高强度加密；即使上传至云端，服务端存储的也只是密文，日常运
 维无法查看明文内容。
   2. **明确授权才核验**：任何人工核实或授权交付操作均严格以用户本人在应用内确认授权及预设规则为前提，平台不进行无授权的隐私
 追踪或定位监控。
   3. **合规运营**：本应用已按国家有关规定完成移动互联网应用程序备案。
