   ## 产品简介

   **幸福传承（SafeCheck）** 是一款专注于**日常报平安**与**个人重要备忘加密保存**的应用工具（支持 **Android APP** 与 **微信小
 程序**）：

   - **日常安全签到**：每天轻点一下即可报平安，支持连续签到统计、日历记录与每日提醒时间设置。
   - **端上加密备忘**：重要账号提示、家庭联系说明、生活备忘等全部在手机本地使用 **AES-256-GCM** 加密保存，支持独立「便签密码
 锁」。
   - **授权关怀机制（VIP 服务）**：在用户本人明确授权并设定规则后，如连续多日未按时签到，平台将启动人工核实并与紧急联系人沟通
 确认，守护独居人群与家庭成员的日常安全。
